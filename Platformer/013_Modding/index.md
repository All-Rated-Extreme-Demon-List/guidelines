# Modding {:modding}

* The use of mods, hacks, exploits, external programs, or previous versions of Geometry Dash that **change physics or inputs, modify hitboxes, show information not otherwise available, adjust the game’s speed, or fundamentally alter gameplay mechanics** (relative to the most recent Geometry Dash update) is not allowed, other than the following exceptions:  
  * Click Between Frames (both default setting and Click on Steps)
  * Custom Keybinds  
  * Globed (No Player Collision)  
  * Show Hitboxes on Death 
* **Just because something does not fall under the above bullet point above does not mean it is automatically allowed.** While we list some examples of what is allowed and disallowed in this section, read the following link for more info on allowed/banned mods, hacks, and programs: [Allowed mods, hacks, and programs](https://docs.google.com/spreadsheets/d/13zirLi-ociDBJ8QyRZs803_WAm68HiSHtnyoAnNPncw/edit?gid=0#gid=0)  
* If you are using a hack menu, Pemonlist and AREDL require you to have the endscreen cheat indicator visible. TPL does not require this.  
* The PlatformerSaves mod is banned. If you want to save completions, please use the in-game Load Save feature (which saves your progress from the last checkpoint).  
* Using any feature that displays player coordinates to aid in making inputs (whether via the vanilla feature in a downgraded version of the game, or via a mod) is not allowed (e.g., Better Info Label mod).  
* If you believe a mod should be added to the whitelist or blacklist, you can submit a request through [this form](https://docs.google.com/forms/d/e/1FAIpQLSd4P0bk7v4QI9U0YcIfGchIgdh4oK12WBIOJqKft5Vn_cauHQ/viewform).  
* If you are unsure about the legitimacy of a mod, contact a member of the records team.
