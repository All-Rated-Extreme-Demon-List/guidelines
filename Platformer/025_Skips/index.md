# Skips {:skips}

* Skips are divided into three distinct classifications, which determines whether a skip is allowed. The classification of skips will be decided by the list team.
* A **Type I skip** does not significantly alter gameplay, and will always be accepted.
* A **Type II skip** is a skip that significantly alters gameplay, but is not a dramatic enough alteration to be classified as a Type III skip. A Type II skip will be accepted **unless it is patched in the level on the servers**. Note that records previously accepted with a Type II skip will remain on the list, even if the classification of the skip later changes to Type III.
* A **Type III skip** is a skip that **dramatically** alters gameplay. A Type III skip will always be rejected. Some examples of Type III skips include but are not limited to the following:
  * Skips that make some aspect of a level/checkpoint a fundamentally different experience
  * Skips that alter the gameplay in a way that is more than just a skip
* The extent gameplay is altered will be determined by how much it differs from the intended route. We **may** make exceptions if an unintended route is easily mistaken as the intended route.
* View [this document](https://docs.google.com/document/d/15IorVLJaITyZ5L9j2gBWxfKSKAz-P0mVEdLt8bZuK1g/edit?usp=sharing) for a list of skip classifications. This list is non-exhaustive. If a skip that you would like to use is not listed on this document, it is highly encouraged to check with a list team before using a skip.
